About Blank Cloacker (required to get to games)

Flip the switch below to continue. This will navigate the tab to a secure blank document and then load the games site so the target domain is not directly visible in the address bar.

Notes: If embedding the games site is blocked by the target site, the cloaker will open the site in a new tab without sending a referrer.

Why this exists

This demo shows how a page can navigate to an intermediate blank document and then load another site inside that blank document. This makes the browser URL bar show about:blank while the iframe displays the target. Edit the GAME_URL in the script below to set the real games address.
